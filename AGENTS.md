# ACM AIR CHARTER

Canonical static source is `acm_design V4/`. Follow
[`acm_design V4/AGENTS.md`](acm_design%20V4/AGENTS.md) when adding HTML, CSS or
JavaScript. Do not treat `acm_design_V1`, `acm_design_V2`, plugins or
`source_assets` as GTD source.

Live WordPress must install published theme ZIPs one version at a time. After
each install a wp-admin popup applies HTML/field/section deltas and offers the
next server version. CSS/JS stay in the theme.
